# Surbhi_CurrencyConverter — Magento 2

Standalone storefront currency exchange converter for Magento.

## Features
- `{website_url}/currencyconverter` storefront page for currency converter page.
- Currency will list loaded from Frankfurter v2 `/currencies`.
- Can swap the currency while converting.
- Also can check Map for conversion rate change for last 30.90,180 days and 1 year.
